PROJECT 01 Machine Learning / Security

ML-Based Network Intrusion Detection System

A real-time intrusion detection system that captures live traffic, turns packets into flows and flags attacks, tested honestly on attack types it never saw in training.

Live Detection Pipeline
LIVE PACKETS ↓ BIDIRECTIONAL FLOWS ↓ FLOW FEATURES ↓ XGBOOST ↓ FASTAPI + SQLITE ↓ REACT DASHBOARD
  • Captures packets with Scapy, rebuilds two-way flows and scores each one in real time behind a FastAPI backend with SQLite, shown on a React dashboard.
  • Evaluated on CIC-IDS2017 by day, not at random: trained on Monday to Thursday, tested on Friday, whose DDoS, port-scan and botnet attacks never appear in training. A random split scored 99.88% accuracy, which I traced to data leakage.
  • At 0.14% false alarms, XGBoost caught 61.93% of the unseen DDoS flows, against 26.68% for a Random Forest at a similar 0.09%.
  • Port scans are invisible in single flows, so a separate tracker counts distinct ports and hosts per source over 60 seconds and alerts during the scan. Covered by 69 pytest tests.
Python Scapy XGBoost Scikit-Learn PyTorch Pandas FastAPI SQLite React
